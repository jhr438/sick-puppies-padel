# Sick Puppies Padel

Seeding, live scores and stats for the Sick Puppies padel tournaments, Dubai.

Live site: https://jhr438.github.io/sick-puppies-padel/

- `index.html` - the app (scores live in Supabase, read-only for viewers).
- `lineup.json` - who is playing next, written by the Tuesday/Friday 11:30 teams task.
